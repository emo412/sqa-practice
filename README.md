# sqa-practice 🧪

SQA (Software Quality Assurance) learning log. Manual testing, automation, and QA concepts.

## Structure
```
manual-testing/
  test-cases/        # test case documents for practice apps
  bug-reports/       # practice bug reports

automation/
  pytest-basics/     # pytest scripts as I learn them
  selenium/          # browser automation (later)

concepts/
  notes-*.md         # theory notes: SDLC, testing types, etc.
```

## Commit Format
`add: <area> - <description>`
Examples:
- `add: manual - login test cases for practice app`
- `add: pytest - first parametrize test`
- `add: concept - testing pyramid notes`
